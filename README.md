# Город в цифрах

Учебный проект по дисциплине «Визуализация данных». Сайт помогает сравнивать районы Москвы по стоимости аренды однокомнатной квартиры и времени до одного из двух кампусов. Три интерактивных графика показывают компромисс между бюджетом и дорогой, стоимость аренды подходящих районов и динамику цен за год.

## Локальный запуск

Требуется Node.js 22 или новее.

```bash
npm ci
npm run dev
```

Откройте адрес, который выведет Vite. Проверка типов и производственная сборка выполняются командой `npm run build`. Для проверки сборки запустите `npm run preview`.

## Данные

Единый набор находится в `src/data.json`. Названия 14 районов Москвы и двух кампусов реальные, числовые показатели синтетические. Период истории аренды длится с декабря 2025 по ноябрь 2026 года. Последнее значение истории совпадает с текущей ценой. Время до кампуса задано для каждой пары «район — кампус» и представляет условную сумму пеших участков, ожидания, поездки и пересадок. Текущие маршруты и рыночные цены сайт не запрашивает.

Фильтры, выбор районов и открытые отчёты хранятся в localStorage текущего браузера. Экран оплаты симулирует успех, отмену и ошибку за 199 ₽. Реквизиты не требуются, списаний и сетевых запросов к платёжному сервису нет. PDF формируется на устройстве с встраиваемым кириллическим шрифтом DejaVu Sans.

## Сценарий защиты за две минуты

1. На главной нажмите «Сравнить районы». Введите 65 000 ₽ и 45 мин, оставьте НИТУ МИСИС. Подойдут 6 из 14 районов.
2. Нажмите на точку графика и покажите карточку, подсвеченную строку и диаграмму аренды. Добавьте Черёмушки и Академический.
3. Перейдите в «Сравнение». Покажите динамику за 12 месяцев и вывод. У Черёмушек аренда ниже, из Академического дорога быстрее.
4. Нажмите «Получить отчёт за 199 ₽», затем «Проверить ошибку» и «Повторить попытку». Скачайте PDF. После обновления страницы отчёт останется доступен.

## GitHub Pages

Проект использует React, TypeScript, Vite, Apache ECharts, HashRouter и jsPDF. Базовый путь сборки — `/gorod-v-cifrah/`. Hash-маршруты работают при открытии прямой ссылки, например `#/overview`, и после обновления страницы.

В публичном репозитории `gorod-v-cifrah` выберите **Settings → Pages → Build and deployment → Source → GitHub Actions**. Workflow `.github/workflows/deploy.yml` запускается при отправке коммитов в `main` и вручную во вкладке **Actions**. После успешного развёртывания GitHub показывает URL сайта в разделе **Settings → Pages**.
